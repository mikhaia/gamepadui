# GamePad UI

Минималистичный полноэкранный лаунчер с навигацией от геймпада. Первичная спецификация находится в [`GamePad-UI.md`](./GamePad-UI.md).

## Что уже работает

- экраны «Избранное», «Библиотека», «Проводник» и «Поиск»;
- поиск по выбранным папкам с переключателем «Приложения / Все файлы»: приложения можно добавить в библиотеку, остальные файлы открываются программой по умолчанию;
- левый сайдбар со списком приложений системы: «Главное меню» в Windows и папки «Программы» в macOS — запуск и добавление в избранное;
- настоящие значки приложений в сайдбаре, Проводнике, поиске и в плитках без обложки: `.app` в macOS, `.exe`/`.lnk`/`.url` в Windows; извлекаются в фоне и кешируются в системной папке кеша;
- ручное добавление и редактирование приложений без автоматического импорта;
- постоянное хранение библиотеки и настроек через Neutralino storage;
- чтение каталогов, добавление `.exe`/`.lnk` и других платформенных файлов из Проводника;
- строка пути в Проводнике по частям (клик — переход в эту папку), выключатель «Скрытые файлы», в Windows — «Этот компьютер» со списком дисков выше `C:\`;
- закреплённые папки слева в Проводнике: переход по клику, порядок ↑/↓, открепление; при запуске открывается первая из них;
- действия над файлами и папками в Проводнике (X или правый клик): открыть программой по умолчанию, открыть папку в Finder/Проводнике Windows, переименовать, удалить в Корзину;
- сортировка в Проводнике по названию, размеру (сначала большие) и дате изменения (сначала новые), вид «плитка» или «список»;
- приблизительный размер папок в Проводнике — по выключателю «Размер папок» (по умолчанию выключен): считается в фоне через `du` в macOS/Linux и PowerShell в Windows, кешируется на 10 минут;
- запуск приложений с необязательными аргументами;
- ссылки на сайты (`http://` и `https://`) вместо пути к файлу: открываются в браузере по умолчанию;
- управление мышью, клавиатурой и стандартным Gamepad API;
- пока окно лаунчера в фоне (например, идёт игра), нажатия на геймпаде игнорируются; повторное нажатие «Запустить» во время загрузки игры не запускает её второй раз;
- системное меню со сном, перезагрузкой, выключением и выходом из системы; подтверждение — в окне лаунчера, им можно управлять геймпадом;
- автозапуск вместе с системой (переключатель в настройках): ключ `Run` в Windows, LaunchAgent в macOS, XDG autostart в Linux;
- обложки из файла, по ссылке, из GameStory и SteamGridDB; пользовательский фон с затемнением/размытием;
- обложки и фон по ссылке скачиваются в системную папку кеша (`GamePadUI/images`) и показываются оттуда — без интернета тоже;
- часы и светлый адаптивный glass-интерфейс для телевизора или монитора;
- заставка с большими часами после простоя: фон лаунчера, своё изображение или видео YouTube (со звуком или без), часы по центру или в углу;
- переключаемые светлая и тёмная темы для разных фоновых изображений;
- выбор монитора в настройках, если их подключено несколько: окно переносится сразу и при каждом запуске (Windows, macOS, Linux с `xrandr`);
- пять акцентных палитр: сливовая, черничная, терракотовая, медовая и пыльно-розовая;
- подсказки, автоматически переключающиеся между клавиатурой, мышью и геймпадом;
- звуки навигации и нажатий (синтезируются через Web Audio, отключаются в настройках);
- локальный SVG-набор иконок без сетевых зависимостей.

## Запуск для разработки

Нужен Node.js 18 или новее.

```bash
npm install
npm run setup
npm run dev
```

`npm run setup` загружает официальные Neutralino-бинарники и клиентскую библиотеку, которые не сохраняются в Git.

## Стили

`resources/styles.css` разбит на пронумерованные разделы (оглавление в начале файла). Цвета берутся только из токенов раздела 1: светлая тема — значения на `body`, тёмная — `body[data-theme="dark"]`, акценты — `body[data-accent="…"]`. Новому компоненту достаточно использовать токены (`--glass-bg`, `--control-bg`, `--tile-bg`, `--field-bg`, `--accent-tint` и др.) — отдельные правила для тёмной темы не нужны.

## Проверка и сборка

```bash
npm test
npm run build
```

Релизные архивы создаются в `dist/`.

## Управление

| Действие | Геймпад | Клавиатура |
|---|---|---|
| Навигация | D-Pad / левый стик | Стрелки |
| Выбрать / запустить | A | Enter |
| Назад | B | Esc / Backspace |
| Действия | X | X |
| Поиск | Y | Y |
| Сменить раздел | LB / RB | Q / E |
| Приложения (левый сайдбар) | View (две рамки) | Ctrl+Пробел |
| Системное меню | Menu (≡) | M |

Мышью приложение запускается левым кликом, а меню действий открывается правым кликом. Системное меню также открывается кликом по кнопке «Меню» в правом нижнем углу, а сайдбар приложений — кнопкой ≡ в левом верхнем углу.

В сайдбаре приложение запускается кнопкой A, Enter или кликом, а в избранное добавляется кнопкой X, правым кликом или звёздочкой. В Windows список собирается из `%APPDATA%\Microsoft\Windows\Start Menu\Programs` и `%ProgramData%\Microsoft\Windows\Start Menu\Programs` (ярлыки `.lnk` и `.url`, без деинсталляторов и «Автозагрузки»), в macOS — из `/Applications`, `/System/Applications` и `~/Applications`.

## Следующие решения

В спецификации пока не определены формат индекса поиска, модель тем, обработка Windows-ярлыков, автозапуск и поведение на Steam Deck. Текущий код изолирует эти части: библиотека, платформенные команды, навигация и UI разделены, поэтому их можно уточнять без полной переделки приложения.
